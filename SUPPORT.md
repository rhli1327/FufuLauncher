# Support

## Documentation First

Before asking for help, please check the official documentation:
**[https://fu1.fun/docs](https://fu1.fun/docs)**

It contains documentation and tutorials covering almost everything, with
detailed categories and full search — most questions can be answered there.

## Still Need Help?

- **Found a bug?** Open an issue using the *Bug Report* template:
  [Issues](https://github.com/FufuLauncher/FufuLauncher/issues/new/choose)
  Please make sure you are on the latest version first.
- **Have a suggestion or feature request?** Use the *Suggestions & Feature
  Requests* template on the same page.

## Security Issues

Do not report security vulnerabilities through public issues or the
documentation site. See [SECURITY.md](SECURITY.md) instead.
